# 请你做的事（临床专家版）

## 一句话

表格里有 198 个来自 ICU 数据库的字段。**逐行判断：这个字段记录的是什么临床概念？如果不属于给定清单里的任何一个，就写 UNKNOWN。**

## 材料

| 文件 | 是什么 |
|---|---|
| `worksheet_clinician.csv` | 你要填的表，198 行 |
| `concept_catalogue.csv` | 可选答案清单，138 个概念名 |

## 怎么填

表格每行给你一个字段的全部信息：

| 列 | 含义 |
|---|---|
| `database` | 来自哪个数据库（MIMIC-IV / MIMIC-III CareVue / eICU-CRD） |
| `source_table` | 来自哪张表（chartevents 床旁记录 / labevents 化验 / nurseCharting 护理记录 …） |
| `field_name` | 字段在原库里的名字 |
| `dictionary_category` | 原库给它的分类 |
| `declared_type` | 原库声明的数据类型（Numeric / Text，空 = 原库没写） |
| `specimen` | 标本类型（Blood / Urine / Ascites …，空 = 原库没写） |
| `unit_recorded` | 实测数据里出现最多的单位（空 = 该字段没有单位记录） |
| `value_p01` / `value_median` / `value_p99` | 该字段全部取值的 1% / 50% / 99% 分位数 |
| `pct_of_stays_with_this_field` | 有多少比例的 ICU 住次记录了这个字段 |
| `observations_per_stay` | 平均每次住院记录多少条 |

你填三列：

1. **`YOUR_ANSWER_concept_or_UNKNOWN`**
   - 从 `concept_catalogue.csv` 里**原样复制**一个概念名（例如 `heart_rate`、`lactate`、`peep_set`）
   - 如果清单里没有对得上的，写 `UNKNOWN`
   - 如果实在判断不了，写 `UNSURE`

2. **`YOUR_CONFIDENCE_1to5`** —— 1 = 完全是猜的，5 = 非常确定

3. **`YOUR_NOTE`** —— 只在你觉得有话要说时写，一句话即可（例如"名字像血压但单位是 %，可能是脉搏氧"）

## 四条规则

1. **不确定不要硬填。** 写 `UNSURE` 对我们比乱猜有用得多。
2. **单位和数值范围优先于名字。** 名字相同但单位/数值范围不合理，就不是同一个东西。例如 `Temperature` 中位数 98.4 是华氏度、36.9 是摄氏度。
3. **标本类型不同就是不同概念。** `Albumin`（血）和 `Albumin, Ascites`（腹水）单位都是 g/dL，但不是同一个概念。
4. **测量方式不同就是不同概念。** 有创动脉压和袖带血压不是同一个概念；呼吸机设定值（set）和实测值（total/measured）不是同一个概念。

## 时间

大约 **1.5–2 小时**。可以分几次做完。

## 不要做的事

- 不要和另一位专家讨论后再填。我们需要两份**互相独立**的判断。
- 不要去数据库里查这个字段的原始 ID。表里给的信息就是全部信息。
