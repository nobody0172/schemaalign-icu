# 人类专家盲测验证包

## 目的

我们的字段—概念参考集是由语言模型仲裁产生的。外部审稿人指出：这构成潜在的循环论证，
需要**独立的人类专家**在盲测条件下裁定一个分层样本，才能确立标注效度。

## 需要两类专家，各一人（都做同一份 198 行样本）

见 `招募说明.md`。两人**独立**标注同一批字段，因此可以同时得到：
- 人—人 Cohen's κ（真正独立的一致性统计量）
- 人—模型一致率（回答"参考集是否可信"）

## 发给专家的文件

| 类别 | 发这几个文件 |
|---|---|
| 临床专家 | `worksheet_clinician.csv`、`concept_catalogue.csv`、`说明_临床专家.md` |
| 数据工程专家 | `worksheet_data_engineer.csv`、`concept_catalogue.csv`、`说明_数据工程专家.md` |

**`_sample_key_DO_NOT_SEND.csv` 绝对不要发给专家** —— 它含模型给出的答案与分层标签，
发出去等于泄题，整个验证作废。

## 抽样设计（198 个字段，专家不可见）

| 分层 | n | 为什么抽它 |
|---|---:|---|
| S1 判为 UNKNOWN 的高覆盖字段 | 70 | 论文"77.1% 字段无对应概念"这一主张直接建立在这批判定上 |
| S2 正例，仅有 LLM 证据 | 50 | 最可能循环论证的一批 |
| S3 两个标注者分歧、经仲裁 | 30 | 本来就难的边界样本 |
| S4 确定性检查报单位/类型/标本冲突 | 28 | 本文方法的作用点 |
| S5 正例，非 LLM 证据（三源一致等） | 20 | 对照组，应接近全对；用来检验专家自身可靠性 |

样本行已随机打乱，专家看不出分层。样本中模型判 UNKNOWN 的占 46.0%。

## 回收后怎么用

1. 人—人 κ → 论文里替换掉目前那个"两个被提示的模型实例"的 κ
2. 人—模型一致率，按分层分别报
3. 在"专家判定"子集上重跑主结果（R@1 / 开放集 AUROC）→ 论文新增一行
4. 专家改动的样本逐条纳入 limitation

## 合规

工作表只含字段级元数据（名称、单位、分位数、覆盖率），**不含任何患者数据**，
也不含 itemid 等主键。可直接发送，无需 PhysioNet 数据使用协议签署方参与。
