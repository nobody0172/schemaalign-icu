# 临床专家：人物画像与任务说明

---

## 一、要找什么样的人

### 核心画像

**一位在 ICU 一线工作过、看得懂床旁监护与化验单的临床人员。**

具体可以是以下任一种：

| 类型 | 具体要求 |
|---|---|
| 重症医学科医生 | 主治医师及以上，或高年资住院医（3 年以上 ICU 轮转经历） |
| ICU 专科护士 | 5 年以上 ICU 床旁工作经验，熟悉护理记录单的填写口径 |
| 呼吸治疗师 | 熟悉呼吸机参数设定与实测值的区别 |
| 麻醉科医生 | 有 ICU 或术后监护病房工作经历 |

### 必须具备

1. **实际管过床**。知道监护仪、呼吸机、血气分析仪日常是怎么记录数据的，而不只是在论文里见过这些指标。
2. **看得懂英文医学缩写**。表格里的字段名是英文原文，例如 `Hgb`、`Hct`、`PEEP`、`FiO2`、`NIBP`、`ETCO2`、`SvO2`、`BUN`、`INR`。
3. **对数值范围有直觉**。看到某个指标的中位数和 1%/99% 分位数，能判断这个范围合不合理、单位对不对。

### 不需要具备

- **不需要**懂数据库、SQL 或任何编程
- **不需要**用过 MIMIC、eICU 这类公开数据库
- **不需要**有科研或发表经历

### 这个人为什么合适

我们要判断的问题本质上是临床问题，不是技术问题。例如：

- 一个叫 `Temperature` 的字段，中位数是 98.4——这是华氏度，不是摄氏度
- `Albumin`（血清）和 `Albumin, Ascites`（腹水）单位都是 g/dL，但不是同一个指标
- 呼吸机的 `set PEEP`（设定值）和 `total PEEP`（实测值，含内源性 PEEP）是两个不同的变量
- 有创动脉压和袖带血压不能混为一谈

这些判断，一个管过床的临床人员几秒钟就能做出，而一个纯技术背景的人可能判断不了。

### 在哪里找

- 三甲医院重症医学科 / 综合 ICU / 外科 ICU / 急诊 ICU
- 医学院附属医院的重症医学教研室
- 呼吸治疗专业（部分院校设在康复医学或呼吸内科下）
- 麻醉科的 ICU 亚专业组

## 二、这个人具体要做什么

### 一句话

**填一张 198 行的表格。每行是一个 ICU 数据库字段的信息，判断它记录的是什么临床概念；如果不属于给定清单里的任何一个，就写 UNKNOWN。**

### 拿到的材料

一个压缩包，里面有三样东西：

1. `标注表_临床专家.xlsx` —— 要填的表，198 行（同时提供 CSV 版）
2. `概念清单.csv` —— 138 个可选的概念名（Excel 版里是第二个工作表）
3. `填写说明.md` —— 详细的填写规则

### 表格长什么样

每一行给出一个字段的全部信息：

| 列 | 内容 |
|---|---|
| 来自哪个数据库 | MIMIC-IV / MIMIC-III (CareVue) / eICU-CRD |
| 来自哪张表 | 床旁记录表 / 化验表 / 护理记录表 / 呼吸治疗记录表 |
| 字段名与缩写 | 原库里的英文名 |
| 原库分类 | 例如 Chemistry、Hematology、Cardiovascular |
| 声明的数据类型 | 数值 / 文本（空 = 原库没写） |
| 标本类型 | Blood / Urine / Ascites 等（空 = 原库没写） |
| 实测单位 | 从真实数据里统计出的众数单位（空 = 该字段没有单位记录） |
| 取值的 1% / 50% / 99% 分位数 | 该字段全部取值的分布 |
| 覆盖率 | 有多少比例的 ICU 住次记录了这个字段 |
| 每住次记录条数 | 平均值 |

### 要填的三列

1. **答案**：从概念清单里选一个（Excel 里是下拉菜单），或填 `UNKNOWN`（不属于清单里任何一个），或填 `UNSURE`（判断不了）
2. **置信度**：1 到 5，1 = 完全是猜的，5 = 非常确定
3. **备注**：只在有话要说时写一句，例如"名字像血压但单位是 %，可能是脉搏氧"

### 判断时的四条规则

1. **不确定不要硬填。** 写 `UNSURE` 比乱猜有用得多。
2. **单位和数值范围优先于名字。** 名字对但单位或数值范围不合理，就不是同一个东西。
3. **标本类型不同就是不同概念。** 血 / 尿 / 腹水 / 胸水的同名化验要分开。
4. **测量方式不同就是不同概念。** 有创 vs 无创；设定值 vs 实测值；床旁快速血糖 vs 实验室血糖。

### 工作量

**约 1.5 到 2 小时**，可以分几次做完，没有时间限制之外的要求。

### 两条硬性要求

1. **独立完成。** 另有一位标注者在做同一份表，两人之间不要讨论、不要对答案。我们需要的正是两份互不影响的判断。
2. **不要用 AI 代填。** 这份标注的全部价值在于它是人做出来的。

### 关于数据

表格里只有字段级的元信息（字段名、单位、统计分位数、覆盖率），**不含任何患者数据**，不涉及任何隐私或伦理审批问题。

### 交回方式

把填好的表格原样发回。**不要改动前面那些列的内容或行的顺序**——靠行号对齐。

### 署名

如果这份标注被采用，会在论文致谢中署名；如果本人希望，也可以列为共同作者。

## 三、这件事是干什么用的（可以告诉候选人）

我们在做一项跨 ICU 数据库字段自动对齐的研究：让程序自动判断"A 库的这个字段"和"B 库的那个字段"记录的是不是同一件事。

目前这套自动方法的正确性是用**另一套程序**判定的，这构成循环论证。我们需要一份**由人做出的、独立的判定**来检验它到底可不可信。

这 198 行是从几千个字段里**有针对性抽出来的**——重点落在最容易出错的地方，所以里面会有相当比例（约四成半）本来就该判 `UNKNOWN` 的字段。**判 UNKNOWN 是正常且频繁的正确答案，不是没做出来。**
